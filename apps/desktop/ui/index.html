Help

The keyboard isn't detected
  1. Pictures need the USB-C cable in wired mode: the 2.4 GHz dongle carries key presses and the clock, but not the screen.
  2. The dongle is fine for the clock: syncing works over 2.4 GHz. If the app says "dongle · clock only", that is expected.
  3. Close the official AJAZZ / Epomaker driver if it's running. Only one program can talk to the screen at a time.
  4. If the app says the device is not permitted, the udev rule is missing. The .rpm and .deb install it; otherwise run the command below once.
Linux: permission denied on /dev/hidraw

Install the rule once, then unplug and replug the keyboard:

sudo install -Dm644 udev/70-ak820.rules /usr/lib/udev/rules.d/70-ak820.rules
sudo udevadm control --reload && sudo udevadm trigger

The rule grants the logged-in user access to the AK820's hidraw nodes (vendor 0c45, products 8009, 800a and fefe).

Limits

Pictures last until you unplug. The keyboard shows what you send only while it stays on the cable in wired mode. Unplugging it, or switching to 2.4 GHz or Bluetooth, brings back its built-in screen. The official AJAZZ tools behave the same way. History (above) keeps your designs on this computer, so putting one back is one click.

The screen is 128 × 128 pixels with 16-bit colour. The keyboard reports its exact frame limit after you connect (up to about 255 frames on current firmware). Sending runs at roughly 30 KB/s, so a long animation takes a couple of minutes: keep the cable plugged in until it finishes. Effects on a still image make a short loop (24 frames by default), which sends in under a minute.

Can I see what's on my keyboard right now?

Only what this app sent or saved. The keyboard cannot send its picture back, so the app keeps its own copy of every design in its history folder. That folder survives restarts and is shared with ak820ctl. Anything sent with the official driver isn't in it.

Clock sync and autostart

Open ⚙ Settings to start the app at login, keep it in the tray, sync the clock when the app starts or the keyboard is plugged in, and re-sync on a timer while it runs. The clock is pushed from this computer, so no network is involved.

If you prefer systemd over the app, the packages also install ak820-clock.timer; enable it with systemctl --user enable --now ak820-clock.timer. Use one or the other, not both.

Updates, source code and bugs

Every release is at github.com/WhatTFF/linux-ajazz-ak820-pro-app/releases. The app checks that page quietly every 12 hours and pops up a window when there is something newer; ⚙ Settings → Updates has a Check now button and a switch to turn the automatic check off.

From that window the AppImage replaces itself in place. RPM and DEB builds download the package to ~/Downloads first, then offer Install now, which asks for your password through the desktop's normal polkit prompt. Prefer the terminal? The exact command (sudo dnf install -y … or sudo apt install -y …) is shown next to a Copy command button, and Later keeps the app quiet about that version until the next one.

The source is at github.com/WhatTFF/linux-ajazz-ak820-pro-app; report bugs there, and include the output of ak820ctl info plus your keyboard's firmware version. Links open in your browser, never inside this window.

Is this safe?

It sends the same commands as the official driver to set the screen picture and the clock. It never touches firmware. Everything happens locally, and your files never leave your computer.
